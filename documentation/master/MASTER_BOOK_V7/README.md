# Nova Star Capital — Master Book V7.0
## Production Candidate
Status: Official Documentation
Classification: Master Book Governance

This Master Book is the official functional and technical reference for Nova Star Capital.

Nova Star Capital is an explainable, governed and institutional-grade multi-asset investment platform where every investment decision must be traceable, measurable, reproducible and justified before execution.

## Core Principle

Explain Before Execute.

No investment decision should move toward execution without:
- a documented source of signal;
- a portfolio impact assessment;
- a risk and governance validation;
- an explainable decision rationale;
- monitoring and reporting coverage.

## Governance Rule

A feature is not considered complete until:
1. the code is implemented and tested;
2. dashboards reflect the behaviour correctly;
3. Daily Review / reporting is coherent;
4. the Master Book is updated.
