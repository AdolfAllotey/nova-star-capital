# Philosophy

Investment Engines are specialised decision systems.

Each engine analyses a specific asset class using dedicated models, data sources and risk constraints.

Engines DO NOT allocate capital.

Their responsibility ends after producing ranked investment opportunities.

Portfolio allocation is exclusively performed by the Portfolio Brain.
