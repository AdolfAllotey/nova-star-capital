# Nova Star Capital
# Learning Engine Standard

Version: V1.0
Status: Official Documentation
Classification: AI & Continuous Improvement

---

# Purpose

The Learning Engine analyses historical decisions in order to improve future trading performance.

It never modifies production behaviour automatically.

Its role is advisory.

---

# Core Principle

The trading engine executes.

The Learning Engine observes.

The governance process validates improvements.

---

# Sources

Learning uses data from:

Decision Memory

Execution History

Portfolio Brain

Risk Engine

Broker Metrics

Market Regime History

Strategy Performance

Portfolio Analytics

# Confidence Calibration

Overestimated confidence

False negatives

Calibration opportunities
