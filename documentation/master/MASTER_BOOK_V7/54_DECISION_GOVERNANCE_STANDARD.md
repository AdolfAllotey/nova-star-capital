# Purpose

This document defines the governance framework for every trading decision made by Nova Star Capital.

Governance guarantees that all decisions remain:

Consistent

Auditable

Explainable

Reproducible

Controlled

---

# Core Principle

No decision exists outside governance.

Every trading decision is subject to governance rules.
