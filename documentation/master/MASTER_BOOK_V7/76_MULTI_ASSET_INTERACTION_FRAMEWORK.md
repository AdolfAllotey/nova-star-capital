# Purpose

Nova Star Capital is designed as a unified multi-asset investment platform.

Each asset class contributes differently to portfolio construction.

This framework defines how all asset classes interact.

---

Market Regime

Risk

Expected Return

---

# Defensive Mode

During defensive regimes:

Increase cash

Increase government bonds

Increase gold

Reduce speculative assets

Reduce leverage

Increase liquidity

---

# Offensive Mode

During offensive regimes:

Increase growth allocation

Increase equities

Increase digital assets

Deploy reserved capital

Reduce defensive exposure

---

# Long-Term Allocation

Strategic allocation remains independent from tactical allocation.

Short-term opportunities shall never compromise long-term objectives.
