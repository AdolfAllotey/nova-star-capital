# NSC MASTER DOCUMENTATION

Ce dossier contient la documentation maîtresse du projet Nova Star Capital.

## Documents

- MASTER_GOVERNANCE.md : constitution du projet NSC
- ARCHITECTURE.md : architecture technique et logique
- CAPITAL_POLICY.md : règles de capital et redistribution
- LONG_TERM_POLICY.md : règles patrimoniales LT
- RISK_POLICY.md : règles de risque et survival mode
- FUNDING_POLICY.md : flux, brokers, réserves
- BROKER_POLICY.md : politique brokers
- MASTER_UI_ARCHITECTURE.md : cockpit UI, family office dashboard, gouvernance visuelle
- COMMERCIALIZATION_ROADMAP.md : stratégie future d’abonnements, signaux et plateforme commerciale
- DECISION_LOG.md : décisions structurantes
- ROADMAP_MASTER.md : prochaines étapes

## Règle d’usage

Toute future conversation ou évolution du projet doit repartir de ce dossier.

Le master distingue clairement :

- le core patrimonial privé NSC ;
- la couche de trading ;
- la couche family office ;
- la future couche commerciale.
