# NSC — ARCHITECTURE

## Architecture logique

DATA
-> INTELLIGENCE
-> BRICKS
-> PORTFOLIO ENGINE
-> RISK ENGINE
-> GOVERNANCE ENGINE
-> EXECUTION ENGINE
-> UI / API

## Principe fondamental

Les briques proposent.  
Le Portfolio Engine alloue.  
Le Risk Engine contraint.  
Le Governance Engine valide.  
L’Execution Engine exécute ou simule.
