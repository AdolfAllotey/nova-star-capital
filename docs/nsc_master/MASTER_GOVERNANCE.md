# Nova Star Capital — MASTER GOVERNANCE

## Vision

Nova Star Capital est conçu comme un système multi-actifs automatisé visant la croissance patrimoniale long terme, l’accumulation d’actifs productifs, le compound du capital et la création progressive d’un family office.

Structure cible :

- Nova Star Capital Holding
- NSC Trading
- NSC Private Equity
- NSC Real Estate

Boucle centrale :

Trading alpha -> Accumulation LT -> Collatéral -> Dette productive -> Nouveaux actifs -> Compound.

## Objectif officiel

Maximiser la croissance patrimoniale long terme avec un risque contrôlé via un système multi-actifs compoundant.

## Brokers officiels

- Binance : crypto
- MEXC : crypto
- IBKR : actions, options, obligations, métaux précieux

## Philosophie

Les briques agressives génèrent de l’alpha.  
Les gains sont progressivement transformés en actifs long terme.  
Les actifs long terme deviennent du collatéral.  
Le collatéral permet de financer de nouveaux actifs via dette productive.

## Règle fiscale

NSC étant une SAS, une réserve d’impôt est prélevée dès le premier euro de gain.

Taux conservateur retenu : 25%.

## Paliers de croissance

### Phase 1 — Hyper croissance

### Phase 2 — Expansion contrôlée

### Phase 3 — Préservation patrimoniale
NAV : > 1M

Objectif : stabilité, résilience, collatéral, conservation patrimoine.
