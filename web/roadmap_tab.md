
# 📍 Roadmap Bot Crypto Ultra

## 🎯 Objectif
Déployer un bot crypto capable d'analyser, backtester et exécuter automatiquement des stratégies basées sur les tendances du marché.

---

### 🚀 Sprint 4 – Nouvelles sources de signaux

- [ ] Reddit sentiment tracker  
  Scanner les subreddits crypto pour détecter les tokens populaires.

- [ ] DEX Volume pump detector  
  Analyser les paires avec fort volume / hausse sur DEX (CoinGecko, DEXTools…).

- [ ] Fusion multi-sources  
  Agréger les signaux Twitter, Reddit et DEX avec un scoring intelligent.

---

### 🤖 Sprint 5 – Automatisation complète

- [ ] Bot décisionnel autonome  
  Détection, stratégie optimale, exécution automatique via API.

- [ ] Déploiement Cloud + cron  
  Bot hébergé sur Render ou Railway avec exécution planifiée.

- [ ] Journal des décisions  
  Stockage des signaux, logs de décisions et résultats de performance.
